# 분기별 비밀번호 변경 안내

2026-11-09 승인: 로그인 완료 후 마지막 실제 비밀번호 변경일부터 90일이 지났거나 변경 이력이 없는 계정에 안내한다.
Company/Partner·Admin/Operator/Guest 모두 같은 기준이다. 로그인/MFA가 완료되기 전에는 표시하지 않는다.
분기는 고정 달력 분기가 아니라 마지막 변경일부터 90일 경과로 계산한다.

- 안내 제목: 비밀번호 변경 안내.
- 마지막 변경일과 경과일을 표시한다. 변경 이력이 없으면 별도로 표시한다.
- “비밀번호 변경하기”는 현재 업무 세션과 Auth 사용자 본인 여부를 확인한 후,
  Auth 서버가 확인한 본인 이메일로 native 재설정 메일을 요청한다. 임의 이메일 입력은 받지 않는다.
- 링크는 운영에서 허용된 `https://partnerdesk-phi.vercel.app/reset-password`로 연결한다.
- 발송 중 중복 클릭을 차단하고 오류 시 재시도할 수 있다. 성공 뒤에는 안내 문구를 표시한다.
- “나중에”/닫기는 현재 로그인 세션에만 적용한다. 같은 탭 새로고침에도 유지하며 다음 로그인에는 다시 판단한다.
- 메일 요청만으로 `password_changed_at`을 갱신하지 않는다. 실제 변경 성공 시 기존 DB 트리거가 기록하고,
  다음 로그인에서 새 변경일을 읽으면 90일 미경과 계정의 안내는 나타나지 않는다.

기존 8자·문자 조합·공백/한글 금지, 전용 검증 API, 30분 유휴 만료·동시접속 제한은 유지한다.
이번 기능은 권장 안내이며 변경 주기 경과만으로 계정을 차단하지 않는다.
